# AOtomeMatch（AOMatch）

乙女游戏角色偏好分析、角色推荐与 AOProfile 分享网站。

## Streamlit Cloud 部署设置

- Repository：`wangaoko-eng/AOtomeMatch`
- Branch：`main`
- Main file path：`app.py`

## 本地启动

```powershell
python -m streamlit run app.py
```

## 上传说明

请将本目录里面的全部文件和子目录上传到 GitHub 仓库根目录。根目录必须直接看到 `app.py`、`requirements.txt`、`data`、`pages`、`utils` 和 `.streamlit`。

当前运行数据包含 478 个唯一角色及 41 个受控标签。
